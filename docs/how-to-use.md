# How to use the Systems Card Game

The Systems Card Game is designed to be adapted to the system, participants, and purpose of a particular workshop or course.

## Basic process

### 1. Define the system and purpose

Decide what participants will map and what the exercise should help them explore.

### 2. Prepare the card set

Use the generic card template to create a set appropriate for the selected system. Existing adaptations can provide examples and may offer a useful starting point.

Participants should also be able to add elements that are missing from the prepared set.

### 3. Create the system map

Participants select cards that they consider important and arrange them on a shared surface. They discuss the placement of the cards and mark relationships between them.

### 4. Explore change or disruption

The completed map can be used to examine how an external pressure, unexpected event, or other change affects different parts of the system.

### 5. Consider responses and futures

Participants explore possible responses, adaptations, and desired futures. The precise format can be adjusted to the purpose of the workshop.

## Adapting the process

The number of participants, facilitation format, card categories, and later exercises can all be adjusted. The documented adaptations and workshop reports show how the method has been used in different contexts.
