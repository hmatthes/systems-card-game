# Documentation templates

These templates can be used to document an adaptation of the Systems Card Game or a workshop, course, or other event in which the tool was used.

## Adaptation template

Use the adaptation template to describe a card set developed for a particular system, topic, or purpose.

The template covers:

- the system and purpose;
- intended users or participants;
- card categories and languages;
- changes made to the general tool;
- available materials;
- guidance for reuse;
- development, contacts, and references.

The Word template will be available for download here.

## Workshop or course report

Use the workshop-report template to document a particular occasion on which an adapted card set was used.

The template covers:

- the adaptation used;
- date, location, and purpose;
- participants and facilitation;
- workshop format and process;
- outcomes and observations;
- lessons for future use;
- contacts and references.

The Word template will be available for download here.

## Contributing an example

Before publishing a completed document, please ensure that it does not contain personal information, photographs, or participant quotations for which publication permission has not been obtained.
