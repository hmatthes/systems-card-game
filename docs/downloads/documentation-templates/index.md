## Contributing an example

Use the **adaptation template** when you have created or modified a card set for a particular system, livelihood, place or topic. Use the **workshop template** when you are documenting a particular workshop, course or other event in which a card set was used.

A workshop should identify the adaptation or card set that it used. If that adaptation has not yet been documented, please consider submitting both templates.

Before sending us a completed document, please ensure that it does not contain personal information, photographs, or participant quotations for which publication permission has not been obtained.

## Adaptations of the game

Use the adaptation template to describe a card set developed for a particular system, topic, or purpose. A fill in Word template can be found for download here: [documentation of adaptations](adaptation-report-template.docx)

The template covers:

- the system and purpose;
- intended users or participants;
- card categories and languages;
- changes made to the general tool;
- available materials;
- guidance for reuse;
- development, contacts, and references.

A comprehensive description of the documentation template can be found here: [Adaptation documentation template](adaptation-template.md)

## Workshop or course report

Use the workshop-report template to document a particular occasion on which an adapted card set was used. A fill in Word template can be found for download here: [documentation of workshops/courses](workshop-report-template.docx)

The template covers:

- the adaptation used;
- date, location, and purpose;
- participants and facilitation;
- workshop format and process;
- outcomes and observations;
- lessons for future use;
- contacts and references.

A comprehensive description of the documentation template can be found here: [Workshop/course documentation template](workshop-template.md)
